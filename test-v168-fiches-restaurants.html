ℹ️ Comment fonctionne Libcomlair ?

Les lieux : Libcomlair récupère des lieux à partir de sources externes et peut aussi afficher des informations ajoutées ou vérifiées dans l’application.

Le classement : les catégories et sous-catégories sont attribuées automatiquement lorsque les données disponibles permettent de les reconnaître.

L’accessibilité : Libcomlair n’invente pas une information d’accessibilité. Lorsqu’elle n’est pas connue ou confirmée, elle reste indiquée comme « à vérifier ».

Les mises à jour : le nombre de lieux, leur classement et leurs informations peuvent évoluer lorsque les sources sont actualisées.

Trouvez un lieu accessible

Restaurants, hôtels, loisirs et services avec des informations d’accessibilité claires.

Catégories

Magasins ▸
ℹ️ Comment sont classés les magasins ?

Libcomlair utilise le type de commerce indiqué par les sources disponibles.

Les magasins peuvent être rangés dans Alimentation, Vêtements, Pharmacie / parapharmacie, Centre commercial, Maison / bricolage, Électronique, Beauté ou Culture / loisirs.

Si le type précis n’est pas suffisamment identifié, le lieu reste visible dans Tous les magasins sans classement incertain.

Bars ▸
ℹ️ Comment sont classés les bars ?

Libcomlair classe les établissements selon le type indiqué dans les données disponibles.

Les sous-catégories sont Bar / café, Pub, Bar à cocktails, Bar musical, Bar d’hôtel et Bar-restaurant.

Lorsqu’un type précis n’est pas confirmé, l’établissement reste dans Tous les bars.

Hôtels ▸
ℹ️ Comment sont classés les hébergements ?

Libcomlair utilise la nature de l’hébergement indiquée par les sources.

Les sous-catégories sont Hôtel, Appart’hôtel, Auberge / hostel, Chambre d’hôtes, Résidence de tourisme et Camping / hébergement de plein air.

Si le type n’est pas suffisamment précis, le lieu reste dans Tous les hébergements.

Restaurants ▸
ℹ️ Comment sont classés les restaurants ?

Libcomlair utilise les informations disponibles dans les sources pour classer automatiquement les restaurants.

Pizzeria, Fast-food et Café / salon de thé sont attribués lorsque le type est clairement identifié.

Cuisine du monde regroupe les cuisines identifiées par origine ou spécialité. Les restaurants génériques sont classés dans Restaurant traditionnel.

Gastronomique n’est pas attribué automatiquement sans information suffisamment fiable.

Un établissement peut donc changer de sous-catégorie si de nouvelles données plus précises deviennent disponibles.

Loisirs ▸
ℹ️ Comment sont classés les loisirs ?

Libcomlair classe les lieux selon l’activité principale indiquée par les sources.

Les sous-catégories sont Cinéma, Musée, Théâtre / spectacle, Bibliothèque / médiathèque, Sport, Piscine, Parc / jardin, Parc d’attractions et Activités culturelles.

Si l’activité n’est pas assez précise, le lieu reste visible dans Tous les loisirs.

Services ▸
ℹ️ Comment sont classés les services ?

Libcomlair se base sur la fonction principale du lieu ou de l’organisme.

Les sous-catégories sont Santé / soins, Administrations / services publics, Banques, Poste, Services sociaux, Aide à domicile, Toilettes publiques accessibles, Accueil / information et Services spécialisés handicap.

Si la fonction précise n’est pas connue, le lieu reste dans Tous les services.

Transports ▸
ℹ️ Comment sont classés les transports ?

Libcomlair utilise les informations des réseaux et sources de transport disponibles pour identifier le mode de transport et les arrêts ou gares.

Les sous-catégories sont Train / Gare, Bus / Arrêt, Métro, Tramway, Taxi / transport adapté et Bateau / ferry.

Lorsque le mode exact n’est pas suffisamment identifié, le point de transport reste dans Tous les transports. Les informations officielles, comme les directions disponibles, peuvent évoluer avec les mises à jour des réseaux.
